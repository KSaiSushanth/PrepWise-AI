UI PRINCIPLES

• Keep the interface simple and distraction-free.
• Prioritize readability and accessibility.
• Use green only for primary actions and highlights.
• Maintain consistent spacing throughout the application.
• Follow a component-based design system.
• Ensure responsive layouts for desktop, tablet, and mobile.
• Keep animations subtle and purposeful.
• Every screen should have a clear call-to-action.
• Maintain visual consistency across all modules.
• Focus on usability over decorative effects.

──────────────────────────────────────────────────────────────────────────────

DESIGN GOAL

Build a modern, premium, clean, and professional AI SaaS interface
that provides users with an intuitive and enjoyable interview
preparation experience while maintaining consistency, accessibility,
and scalability throughout the application.
